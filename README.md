## Week 2 – Exploratory Data Analysis and Visualization

### Objective
Performed Exploratory Data Analysis (EDA) and visualization on the cleaned laptop dataset.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Analysis Performed
- Descriptive statistics
- Brand distribution
- Laptop type analysis
- Price distribution
- RAM vs Price
- Screen Size vs Price
- Price by Laptop Type
- Average Price by Brand
- CPU Brand Analysis
- Operating System Analysis
- Correlation Analysis
- Touchscreen and IPS analysis

### Key Findings
The analysis identified relationships between laptop specifications and price. RAM showed a positive relationship with price, while screen size showed a weaker relationship. Laptop type, brand, and display features also showed differences in pricing.
